**Никакие дополнительные вложения не требуются.** Большие файлы не входят в обязательный startup context.

1. `05_PRIMARY_EVIDENCE/FINAL_10H_JSONL/` — **все 65 JSONL** финального прогона, извлечены из `прогона-закончен.7z`, сохранены побайтово. Индивидуальные SHA-256: `05_PRIMARY_EVIDENCE/FINAL_10H_JSONL_INDEX.tsv`. Оригинальный 7z: SHA-256 `bc95e4a1d7460963f1ed836c75f9ecd51c5597875ee76d1e48deb0c492679239`. Не приложен повторно, поскольку все его data members уже разложены без потерь.

3. `05_PRIMARY_EVIDENCE/ARCHIVED_24H/zapret-maintainer-24h-forensic-and-repo.7z` — самостоятельное более раннее 24-часовое evidence. Это *вложенный исходный архив*, он находится здесь, а не внешнее обязательное вложение; читать только для проверки старых фактов.
4. `06_HISTORICAL_REFERENCES/` — **только уникальные по SHA-256** ранее собранные файлы: старые policies/skills, audits, smoke-test logs, скриншоты, original scripts, ранее утверждённые/предложенные patch documents, ТЗ. Повторные экземпляры не копировались. Полная карта исходных путей: `05_PRIMARY_EVIDENCE/HISTORICAL_IMPORT_INDEX.tsv`.
