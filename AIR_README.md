Начать с [`07_AIR/README_START_HERE.md`](07_AIR/README_START_HERE.md). Подробный словарь: [`07_AIR/07_GLOSSARY_RU.md`](07_AIR/07_GLOSSARY_RU.md). Для истории изменений: [`07_AIR/CHANGELOG.md`](07_AIR/CHANGELOG.md).

Предыдущая `.git`-история реконструирована из исторических снимков и описана в [`GIT_HISTORY_NOTICE.md`](GIT_HISTORY_NOTICE.md); новые AIR-коммиты составляют продолжение этой истории.
