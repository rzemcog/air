# Компоновка без внешних зависимостей

В комплект включены действующие краткие документы, реконструированная Git-история, уникальные historical references, raw финальные JSONL в одном исходном 7z, три D1 JSONL и ранний 24h evidence 7z. Все находятся внутри одного ZIP.

**Размер исходного финального 7z:** 46926362 bytes, SHA-256 `bc95e4a1d7460963f1ed836c75f9ecd51c5597875ee76d1e48deb0c492679239`. Его содержимое: 65 JSONL, 189.1 MiB до сжатия. Извлечение каждого JSONL проверено по индивидуальному digest при сборке первой промежуточной версии; имя и digest есть в `05_PRIMARY_EVIDENCE/FINAL_10H_JSONL_INDEX.tsv`. Вместо 65 распакованных копий сохранён исходный 7z, поэтому это не дублирование.

Текстовые решения/разделы не упакованы в старые ZIP-копии. Карту SHA-256-дедупликации ранее сохранённых уникальных источников содержит `05_PRIMARY_EVIDENCE/HISTORICAL_IMPORT_INDEX.tsv`.

`git` отслеживает только выбранные текстовые изменения, не raw evidence; исторические коммиты синтетические. Не коммитить raw transcripts в Git.

Внешние вложения: **0**. Весь source доступен из этого ZIP для адресного чтения.
