# Реконструированная, НЕ исходная Git-история

Этот `.git/` создан 18.10.2026 специально для handoff, по точным байтам исторических файлов и текущих согласованных артефактов. **Ни один synthetic commit не является реальным коммитом пользователя.** Даты коммитов означают момент упаковки; последовательность отражает логически наблюдаемые состояния файлов, а не гарантированную хронологию редактирования.

- `snapshot-baseline`: исторические original/reference файлы из старого handoff.
- `snapshot-bootstrap-proposed`: предложенные изменения AGENTS/ENTRYPOINT/docker, **не подтверждённая установка**.
- `snapshot-output-candidate`: кандидат политики §2/§3; **не финальная редакция**.
- `snapshot-approved-output`: согласованный конечный артефакт политики; **не подтверждённая установка**.
- `snapshot-handoff`: итоговые документы, гипотезы, выводы из транскриптов.

`git diff snapshot-baseline..snapshot-approved-output -- 01_CURRENT/output-policy.md` даёт сравнение политик. `git log --oneline --all` показывает модель версий, **не историю исходного репозитория**. Данные аудита подтверждают поведение агента отдельно и Git не заменяет исходный JSONL.
