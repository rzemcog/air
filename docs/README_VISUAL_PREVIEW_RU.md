# Визуальное чтение документации AIR

Документы AIR написаны в Markdown; оформление и интерактивность определены локальными файлами `air.css` и `air.js`. Для просмотра используется [MdStyled](https://github.com/OsamaAbuSitta/MDStyled) в VS Code.

## Как открыть

1. Откройте корень репозитория AIR в VS Code и установите MdStyled (`OAS.mdstyled`).
2. Откройте `README.md` или документ из `docs/` командой **Open with MdStyled** / **MdStyled: Open Preview**.
3. Режим **MdStyled Edit** выбирает встроенную редактируемую тему вместо CSS/JS документа. Для редактирования с сохранением темы AIR используйте обычный Markdown-редактор VS Code рядом с предпросмотром.

## Возможности и структура

- `docs/air.css`: общая типографика, адаптивные карточки, таблицы, схемы и состояния.
- `docs/air.js`: необязательная подсветка ветвей схем; все ветви и смысловые подписи остаются доступны без JavaScript.
- `docs/01_ARCHITECTURE_RU.md`: схема архитектурных границ и pipeline resolver.
- `docs/05_EXPERIMENTAL_TZ_RU.md`: рабочая схема экспериментов.
- `docs/10_IMPLEMENTATION_DRAFT_TZ_RU.md`: карта зависимостей проекта.

MdStyled читает `@style` и `@script` относительно каталога самого Markdown-файла. В документах `docs/` подключение выглядит так:

```md
<!-- @style: ./air.css -->
<!-- @script: ./air.js -->
```

В корневом README используются `./docs/air.css` и `./docs/air.js`. Библиотеки с CDN и внешняя телеметрия для темы не нужны.

## Границы оформления

Тема меняет только представление Markdown и не задаёт архитектурных решений AIR. Исходные тексты остаются читаемыми без MdStyled; сложные HTML-схемы при просмотре без темы отображают содержание без сеточного оформления. Новые диаграммы должны сохранять текст и смысл при отключённом JS и соответствовать [skill оформления](../skills/mdstyled-documentation/SKILL.md).
